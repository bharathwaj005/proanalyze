Built for practical sequence analysis

A small, transparent starting point for a broader protein-engineering workflow.

🧬

Flexible sequence input

Read standard FASTA records or a plain-text sequence without a header. Multiline sequence input is supported.

📊

Physicochemical profile

Calculate molecular weight, theoretical pI, aromaticity, instability index, aliphatic index, GRAVY and extinction coefficients.

🔬

Sequence comparison

Compare sequences with global alignment using BLOSUM62 and inspect residue identity and gaps.

📄

Useful output formats

Produce readable terminal reports or export results as JSON and CSV for downstream analysis.

🪶

Lightweight starting point

Sequence analysis runs on a standard CPU; structure prediction and molecular dynamics are not included in v0.1.

🧪

Research-minded design

Outputs are labelled as theoretical estimates. They should be interpreted in context and validated when needed.

Quick start

Install Biopython, then run ProAnalyze from your terminal.

python -m pip install biopython

# Analyze a headerless plain-text sequence
python seqforge.py analyze protein.txt

# Analyze a FASTA file
python seqforge.py analyze protein.fasta

# Save machine-readable results
python seqforge.py analyze protein.fasta --format json --out report.json

# Compare two sequences
python seqforge.py compare wildtype.fasta variant.fasta

Input files should contain the 20 standard amino-acid symbols for v0.1 physicochemical calculations. Values are sequence-derived estimates, not experimental measurements.
